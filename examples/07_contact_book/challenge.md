# Contact Book — Student Challenge

## Level: Intermediate

### Challenge 1 — Change something

Make one visible change without asking for the answer.

### Challenge 2 — Add a feature

Add a feature that is not already in the example.

### Challenge 3 — Handle a mistake

Think of something a user could enter or do that might break the program. Make the program handle it politely.

### Challenge 4 — Explain the code

Be able to explain:
1. What data the program stores.
2. Which function does the main work.
3. Which event starts that function.
4. How the page changes after the function runs.

### ⭐ Bonus challenge

Add a feature that makes the project more useful in real life.

### Teacher rule

Students should attempt the challenge before looking for a solution. The goal is not to type the most code. The goal is to understand why the code works.
