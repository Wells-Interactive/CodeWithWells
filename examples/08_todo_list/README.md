# To-Do List

**CodeWithWells Example 08 · Intermediate**

## 🎯 What are we building?

Build a task manager where students can add, complete, and delete tasks. Tasks survive a page refresh.

## 🧠 What you will learn

- events\n- arrays\n- objects\n- localStorage\n- DOM

## ▶️ How to run it

1. Open this folder in VS Code.
2. Open `index.html` in a browser.
3. For the best experience, use VS Code Live Server if it is available.
4. Open the browser Developer Tools and watch the Console when debugging.

## 🔎 Teacher explanation

Don't try to explain the whole project at once.

Start by asking:
- What information does the program need?
- Where is that information stored?
- What happens when the user clicks a button?
- Which function performs the work?
- How does JavaScript change the page?

Then trace one user action from the HTML input/button into JavaScript and finally back to the page.

## 🧪 Guided exercises

1. Read every line before changing anything.
2. Change one piece of text or data.
3. Add one small feature.
4. Test the feature.
5. Break something deliberately and use the browser Console to find the problem.
6. Fix it without copying a complete solution.
